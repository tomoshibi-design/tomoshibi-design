ともしび意匠室 仮Webサイト

構成：index.html（トップ） / about.html（プロフィール） / contact.html（お問い合わせ）

公開前に行うこと：
1. script.js の YOUR_EMAIL@example.com を実際のお問い合わせ先に変更する。
2. about.html のプロフィールを確認し、必要に応じて経歴や氏名を追記する。
3. 各HTMLファイルの https://www.instagram.com/ をご自身のInstagramプロフィールURLに変更する。
4. GitHub Pages等にフォルダ内のHTML、CSS、JavaScriptファイルをアップロードする。

お問い合わせはメールアプリを開く方式です。フォームの自動送信をご希望なら外部フォームサービス等の導入が必要です。
外部Google Fontsを使用しているため、ネット接続がない環境では代替フォントで表示されます。
